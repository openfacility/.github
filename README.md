# openfacility/.github

The profile of the OpenFacility organization on GitHub. [profile/README.md](profile/README.md) is the page shown on https://github.com/openfacility. Edit it and push; the page updates at once.

[assets/](assets/) holds the logo (cube and wordmark, white for dark backgrounds, navy for light ones) and two square 500×500 images for the organization's avatar: `openfacility-avatar.png` (white cube on navy) and `openfacility-avatar-light.png` (navy cube on white).
